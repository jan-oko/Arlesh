- **Habit occurrences follow their own windows.** An item with a Cycle Scope — "Morning", "Tuesday" — was live for its whole repetition; each occurrence now has its own window and lapses when it ends. An occurrence whose window has not opened is hidden by Plan, Start and Do and shown by All. An item with several cycles draws one occurrence per cycle, each ticked separately. A done occurrence archives once its window passes instead of staying live.
