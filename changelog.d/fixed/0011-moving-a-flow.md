- **Moving a Flow moves the Flow, and not one of your Domains.** Cutting and pasting or dragging a Flow left it in place and moved whichever Domain, Project or Tag shared its database number instead; if one of yours seems to have wandered, this is why, and moving it back is now safe. A Flow's **Target Node** is now optional and defaults to wherever the Flow lives, so its repetitions move with it; a target you set yourself stays put, and clearing it with **×** now saves. Existing Flows that only targeted their own parent are converted, so nothing moves.
