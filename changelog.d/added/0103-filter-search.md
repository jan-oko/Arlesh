- **Add filters from the keyboard with `Ctrl+F`.** A search box in the style of `Ctrl+O` lists every filter the current view has — tags, statuses, Verdict, Scope, the yes/no pills, and Private, Archived and Backlog — and narrows as you type; Under and Depends on search every node once you start typing. Enter adds as All, Shift+Enter as Any, Alt+Enter as Not, and the box clears and stays open so you can add several in a row. Esc closes it.
