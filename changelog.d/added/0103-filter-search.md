- **Add filters from the keyboard with `Ctrl+F`.** Type a tag, a status, a Verdict or Scope value, Blocked / Agentic / Asynchronous, Private, Archived or Backlog — or, in the List View, any node's name to filter by **Under** or **Depends on** it — and pick from the matches. Enter adds as All, Shift+Enter as Any, Alt+Enter as Not, and the box clears and stays open so you can add several in a row. Esc closes it.
