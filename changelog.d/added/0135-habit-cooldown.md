- **Habit cooldown.** A Window Habit can now rest between completions: set a **Cooldown** in the Habit editor (after the Gap) — days for a weekly Habit, weeks or days for a monthly one, parts of the day for a daily one. After you complete an iteration, the next one stays Pending until the cooldown has passed: a weekly Habit done on Saturday with a one-day cooldown opens next week on Monday, not Sunday. Start hides it until then and All shows it, and you can still tick it early. A cooldown as long as the Habit's window is refused.
  **Done date.** A Done Task's editor now shows when it was done, under Advanced, and lets you set it back — so something ticked late counts from when it was really done, for a Habit's cooldown and an Interval Habit's next window alike. A date in the future is refused, and saving a done Habit occurrence again no longer moves its done time to the moment of saving.
