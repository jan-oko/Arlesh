- **The amber Overdue border in every view.** List View rows and Steps, Plan and Zen View cards now draw the amber border an Overdue node has on the Mindmap. A selected Mindmap node that is Overdue keeps a selection border of its own colour, so you can see both at once. In the Zen View it can be turned off: Settings → Zen → *Show the overdue border on cards*. Screen readers hear "Overdue" on every Overdue item.
