- **Subagents as child agents.** A subagent dispatched from an attached Claude Code session (with the `arlesh-notify` mod) is registered as a child of the session's agent and listed under it in Settings → Agents. It claims the Task its brief names, only inside the session's Claim, and sees and writes only that sub-Claim, while the session keeps its whole Claim. When the subagent stops its Claim is paused and the child stays listed as Paused; when it is resumed the Claim resumes. The child is removed when its Task is set Done or its parent agent is removed, and Ctrl+Z brings it back. A child shares its parent's account, so it has no Lock of its own. In the terminal, the subagent's row shows the Task it is on.
