- **Agents are told when a wait they raised changes.** The MCP endpoint (in the app and in `arlesh-server`) now serves a second stream, `/events/expectations` (also as a long poll that answers JSON), which sends a typed event for each wait that is released, reopened, archived or deleted, and `arlesh_waits` gains `watch` (start following waits you did not raise) and `get_many`. The new `arlesh-notify` Claude Code plugin (`plugins/arlesh-notify/`, installable from this repository) long-polls it and wakes the session with a short "Arlesh notification" pointing at the wait, so an agent can end its turn after asking a question instead of polling. Without the plugin nothing changes: agents ask in the conversation too.
