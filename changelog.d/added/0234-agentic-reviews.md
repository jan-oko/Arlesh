- **Agentic reviews.** An agent hands finished work back with a review: a summary, links (a PR, a doc, a build) and a list of things to try by hand. A Task reading Review shows it on its card and in its editor, where you answer with Approve or Request changes and a note of your own; Approve is your word to merge the PR when there is one. Either way the Task goes back to On Agent. The status row shows a different icon for an open review than for an open question. Links open only for web addresses, and an agent can neither overwrite your verdict nor raise a review under a task it has not claimed.
