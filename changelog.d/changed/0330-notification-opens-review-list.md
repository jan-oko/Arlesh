- **A question's notification opens the Review list.** Clicking an agent's question or review notification on the desktop (Linux) brings Arlesh to the front and shows a List tab on the Review preset with that Task selected and that question's answer box focused; an already-open Review tab is reused. Tapping it on the phone replaces the current view with the Review list, the Task selected and the question scrolled into view (the keyboard does not open). If the question is already answered, the list still opens.
