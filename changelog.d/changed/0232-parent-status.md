- **A parent reads the work under it.** A Task with sub-tasks now shows Started or In Progress as soon as work under it has begun (and Started once anything beneath it is done), instead of staying To Do. You can still set its own status by hand; it never reads lower than its sub-items say, and the click and `Enter` cycle skips any status below that: a Done parent over a Done sub-task goes to Started, not To Do. In the Task editor, the statuses a Task cannot hold are greyed out with a note saying why: anything on a Compound Task, a status below what its sub-items make it read, and Done while a sub-item is open. A Task cannot be set Done while anything under it is still open, including backlogged sub-tasks, pending waits and unresolved Commitments: the press, the editor and the MCP all refuse, with a note saying what is left. Finish or archive what remains first. A parent already Done stays Done. A Compound Task now also reads On Agent or Review from its Agentic sub-tasks (Doing or In Progress still wins). The Zen View leaves out a parent that reads In Progress only from its sub-tasks, since the sub-task you are working on shows anyway; one you set In Progress yourself stays.
