- **The Claude Code plugin is now called `arlesh`.** It was `arlesh-notify`, but it also attaches your session and its subagents to Arlesh, so the name now says so. Install it with `/plugin install arlesh --marketplace jan-oko/Arlesh`. An installed `arlesh-notify` is not renamed in place: uninstall it and install `arlesh`. Behaviour is unchanged, but the new plugin starts with an empty store, so a session attaches again with a PIN.
