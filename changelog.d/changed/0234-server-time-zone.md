- **A server keeps your time zone.** The server now has a time zone setting, `ARLESH_TIME_ZONE` (or `--time-zone`), an IANA name such as `Europe/Berlin`. "Today", the parts of the day, Overdue and Missed on a board a server publishes are judged in it, so a server in a container no longer shows UTC's day. Unset, it uses the server machine's own zone as before. A name that is not a zone stops the server from starting, saying so.
