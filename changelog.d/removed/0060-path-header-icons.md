- **The List View's path-header icons, and the switch for them.** A path header used to open with a
  kind glyph for the node its run hangs from, on by default, turned off from **Path icons** in the
  settings popover. Both are gone: a header is now its titles, their separators and the `+` that
  creates a task under them. The glyph competed with the very titles it was there to qualify, and
  the Mindmap already says what kind each node is. Nothing else changes — the same `NodeIcon`
  vocabulary still marks Mindmap nodes and task rows — and an existing stored preference is simply
  ignored rather than migrated.
