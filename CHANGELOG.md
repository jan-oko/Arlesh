# Changelog

All notable changes to Arlesh are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).
Arlesh is a personal app in live preview with no release cycle, so new entries collect under
`[Unreleased]`; the numbered sections below are kept as history.

---

## [Unreleased]

### Added
- **Archive a Domain.** A Domain you no longer need can be archived instead of deleted, so its history stays. Right-click it in the Mindmap and choose **Archive**, or turn on **Archived** under **Advanced** in its editor. Plan and Start then hide it and everything inside it, the same way they hide an Archived Project. Set the **Archived** pill to Include to see it again, and choose **Unarchive** (or turn the switch off) to bring it back as it was.

- **Review pill in the Zen View.** The Zen View's Filter menu has a **Review** pill (key **R** in the menu) that shows the agentic tasks waiting on your answer. It is off by default, so Zen now leaves those tasks out until you turn it on. The setting is kept with the tab. Do, Start and the List View still show Review as before.

- **Downloadable builds for Linux and Windows.** Every commit to master publishes builds to the rolling *latest* pre-release on GitHub, and each `vX.Y.Z` tag gets a release of its own. Linux gets an AppImage and a tarball of the binary, built to run on current distributions. Windows gets a per-user setup `.exe` and an `.msi`; they are not signed yet, so the first run shows SmartScreen's warning (**More info**, then **Run anyway**). Data lives in `%APPDATA%\com.atai.arlesh`, and the tray works as on Linux.

- **Archive a Task or Commitment by hand.** Right-click it on the Mindmap or in the List View and pick **Archive**, or turn on **Archived** in its editor's Advanced section. The whole branch reads as archived and leaves Plan, Start and Do; **Unarchive** brings it back as it was. Either is one **Ctrl+Z**.

- **Subtasks inherit their parent's Plan.** A Task with no Plan of its own reads the nearest Plan above it, narrowed to its own Time Scope; it shows as a fainter calendar badge and read-only in the editor, naming its source. Start, the filters, the Plan View and the MCP all read it. A Plan of its own must sit inside the inherited one: a change that breaks this is refused with the Tasks named, and narrowing a parent's Plan asks whether to clamp, clear or cancel the subtasks' own Plans, as one undo step.

- **Richer Flow and Habit templates.** A template's steps carry the fields of their kind — tags, block reasons and, for a Task, Backlog, Asynchronous (with its wait template), Agentic and Compound — and every occurrence or started Task takes them unless you change it there. A template can hold **Commitment** and **wait** items beside Tasks and Goals, each repeating per iteration. A cycle can be marked **Planned**, planning each occurrence into its own window, and a task Habit's root can be planned into each iteration's window. Changing a step's cycles in a way that would drop recorded occurrences asks first.

- **Filter additions.**
  - **Ctrl+F** adds filters from the keyboard: type a tag, a status, a Verdict or Scope value, a flag, or (in the List View) a node's name for **Under** / **Depends on**, then **Enter** adds it as All, **Shift+Enter** as Any and **Alt+Enter** as Not. Filters you already have are listed first, to change or remove.
  - The List View can show or hide **Tasks**, **Commitments** and **Expectations** rows; with the Filter menu open, **T** / **C** / **E** toggle them and **A** / **W** / **B** / **P** add the Agentic, Asynchronous, Blocked and Private pills. **Ctrl+P** in the menu toggles Private Mode.
  - New pills: **Agentic**, **Asynchronous**, **Private** (while Private Mode is on) and, beside Archived and Backlog, **Delegated** and **On Agent**.
  - The Filter button wears a dot when a filter is set that no chip shows. **Esc** closes the Filter menu in every view.

- **Expectations: waits your tasks depend on.** A new kind of node for something outside your own action — a build finishing, someone replying. Create one with **Shift+E** anywhere a Task can live; it carries a Time Scope, tags and notes, is Pending until you release it (**Enter** or a click on its icon), and can be archived. A Task that depends on a pending Expectation reads as blocked, and the dependency picker offers Expectations beside Tasks and Goals.

  **Check every** (N minutes, hours, days, weeks, months or seasons, from today or a day you pick) puts a "Check: …" Task under the wait each time a check falls due; it is an ordinary Task with its own editor, and completing it schedules the next. The prefix is set in Settings → Expectations. A released wait archives once its window has passed, or at once if it has none. The List View has an **Expectations** option (**Alt+E**) listing every pending wait, and Plan and Start show waits by their own rules — a wait with checks is still shown under Start unless you turn on *Start hides waits that have checks* in Settings → General.

- **Delegation you can see.** A delegated Task wears a paper-plane badge ("Delegated to Tuli") in every view, and carries a wait named for who is to finish it — "Tuli finish: Book the venue" — released when the task is done, while what it waits on stays in view. A **Delegated** pill in the Filter menu decides where delegated Tasks show: off, Plan and Start hide them; **Include** shows them; **Exclude** hides them everywhere. The Zen View shows only what you hold.

- **Create a node of a given kind with Shift and its initial.** On the Mindmap and in the Steps View, **Shift+D**, **Shift+P**, **Shift+G**, **Shift+T**, **Shift+C**, **Shift+I**, **Shift+E**, **Shift+F** and **Shift+H** create a Domain, Project, Goal, Task, Commitment, Info, Expectation, Flow or Habit under the selection. Most drop you straight into naming it; Commitment, Flow and Habit open their editor first (**Shift+H** opens it with Repeating already on). Where the kind cannot live, nothing is created and a notice says where it can. Inside a Flow template the same keys create flow items: Task, Goal, Commitment and wait items.

- **Python bindings and `arlesh-server`.** A Python package, `arlesh`, opens your Arlesh database and runs the app's own logic on it: read the whole board with everything Arlesh derives, create, edit, move and delete any node, and call the scope, lifecycle and Habit rules directly. It opens read-only unless given a client name, and refuses to write while the app is open unless forced; the app's undo never touches a script's changes.

  `pip install 'arlesh[server]'` adds `arlesh-server`, which serves the board over HTTP, MCP included at `/mcp`. Each device needs a token from `arlesh-server token add <name>`, which can be revoked and is recorded on every change it makes. It listens on this machine only unless given `--host`, serves HTTPS with `--tls-cert` and `--tls-key`, and will not start while the app or another server holds the database unless given `--force`.

- **An MCP server, so Claude and other agents can work with your board.** While Arlesh runs it serves MCP on this machine at `http://127.0.0.1:4747/mcp` — connect with `claude mcp add --transport http Arlesh http://127.0.0.1:4747/mcp`. It reads the same live data the app draws.
  - **Access.** An agent sees only the **MCP roots** you add in Settings → Agents, and never private nodes. With no roots it sees nothing. Nodes it can see wear an antenna badge.
  - **Reading.** The board arrives in pages, and can be filtered exactly as the app filters it: the presets, the Archived, Backlog and Delegated pills, tags, Private Mode, a Plan scope, and the List View's pills. Every node has a short id an agent can name it by.
  - **Writing.** Inside its roots an agent can create Tasks (always Agentic) and edit, move, archive and set the status of Agentic Tasks: title, brief, Time Scope, Plan, Due, on-exit choice, Asynchronous, Compound, block reasons, tags, dependencies and delegation to a person. A status change is a compare-and-set, so two agents cannot claim the same Task. It can also leave Info notes under its Tasks and raise waits and questions. Nothing is ever deleted, and an agent's writes never enter your undo stack.
  - **Port.** Settings → Agents sets the port (4747 by default), shows whether the endpoint is running, and can restart it. `ARLESH_MCP_PORT` overrides it.

- **Agentic tasks: work an agent can take.**
  - **The flag.** Mark a Task **Agentic** in its editor's Advanced section (Inherit / Agentic / Not agentic), or toggle it with **A** in any view. The flag passes down the branch, and any Task in it can opt out with Not agentic. Agentic Tasks show a bot-head badge, and the List View can filter by it. Only Tasks can be agentic.
  - **The brief.** An agentic Task carries a brief that it does not inherit: a priority (MW, A, B or C), Spec, Design, Acceptance criteria and Notes. It cannot be started without a Spec.
  - **Statuses of their own:** **To Do**, **On Agent** (an agent holds it), **Review** (its agent has asked you something), **Doing** (you are on it) and **Done**. **Enter** cycles Review → Doing → Done → To Do and takes an On Agent task over; **Alt+Enter** hands a task you are Doing back to its agent. On Agent work is hidden from Start, Do and the Zen View unless the **On Agent** pill is on; Review comes first everywhere.
  - **Questions.** An agent can raise a wait under its task with a question for you, which puts the task in Review. Answer it in the task's editor or on its Zen card (**Send** or **Ctrl+Enter**) and the task goes back to the agent. An agent can also wait on something else, such as CI.
  - **Short ids.** The Task editor shows a Task's short id, the one agents use, with a Copy button, and "Blocked by" names a dependency by it: "Blocked by task 6f3 (Write spec)".

- **Interval Habits, cooldowns and done dates.**
  - An **Interval** Habit has one open occurrence at a time; complete it and the next one starts the Gap after — "every three weeks from the last haircut". An open one past its window stays, flagged Overdue. An Interval Habit can be unscoped. Commitment Habits can run on an Interval too.
  - A Window Habit can take a **Cooldown**: after an iteration is done the next one is blocked ("Cooling down until Mon 5 Oct, 02:00") until it passes.
  - A Done Task's editor shows when it was done and lets you set it back, so something ticked late counts from when it was really done. Achieving a Goal, releasing a wait and judging a Commitment record their time as well.

- **Zen View: only what you are doing now.** A new view (**Ctrl+J**) showing the Tasks you hold In Progress as a grid of cards that fills the window, bigger when there are fewer; delegated Tasks are left out. Review cards for agent questions come first. Above the grid sit strips for unjudged Commitments and open Expectations on people, each switchable in the Filter menu. The List View's keys work here, except the ones that create; the arrows move across the grid and up into the strips. Settings → Zen chooses whether cards show badges, the overdue border, Started tasks and compound tasks.

- **List View additions.**
  - **Ctrl+O** searches every node on the board and enters the one you pick, as on the Mindmap. The List and the Mindmap share one location, and entering a subtree leaves your filters alone.
  - **Creating and deleting:** **Shift+Enter** creates a sibling Task, **Tab** a child Task, and the **+** at the end of each path header adds one under it. A new task opens straight into its title, and **Escape** discards it. **Delete** removes the selected row, with the Mindmap's confirmation and undo.
  - **Scrolling:** the list follows the selection, **J** / **K** scroll without moving it, and **Ctrl+Home** / **Ctrl+End** select the first and last rows.
  - **Alt+U** selects the Unblock preset.
  - **Sections at the top:** a **Review** section for Agentic tasks waiting on you; under Start, an **Overdue** section (Settings → List → *Overdue first under Start*, on by default); and an optional **Asynchronous** section (*Asynchronous first*, off by default).

- **Settings modal.** The gear in the top bar opens a settings modal with pages — General, Mindmap, List, Steps, Plan, Windows & tray, Expectations, Agents and Zen — in place of the popover whose switches came and went with the view. Every setting is reachable from any view and keeps its value. **↑** / **↓** move between pages; **Escape** closes it.

- **Agent capacity lock and agent status.** While agents are at capacity, every Agentic task that isn't done is blocked with the reason "Agents at capacity" (work already under way keeps its status). Agents set and clear the lock over MCP; you can too, in Settings → Agents. A bot head in the top bar shows when agents need watching — the lock on, a question waiting for you, an agent waiting on something else, or work on an agent — with counts in its tooltip and a menu to clear the lock or list the work. *Show agent status in the top bar* turns it off.

- **Compound tasks.** Press **V** on a Task, or turn on *Compound* in its editor, and its status follows everything beneath it: Done when every sub-item is done, In Progress when any is, Started when any has begun, To Do otherwise. When every open sub-item is blocked, the compound is blocked too. Its glyph gets a dashed ring, and setting its status by hand is refused. Turning it off keeps the status it was showing.

- **A searchable keyboard cheat-sheet.** **Ctrl+Shift+/** opens a sheet listing every shortcut, generated from the bindings themselves. It has a tab per area — Global, Filters, Tabs, each view and the Scope pickers — opens on the view you are in, and searches descriptions and keys as you type. **←** / **→** switch tabs, **PgUp** / **PgDn** scroll, and **Esc** clears the search, then closes.

- **A Due for every Task, and Overdue measured against it.** A Task can carry a **Due**, the scope by which it should be finished, set in the editor beside the on-exit choice (now labelled **Keep Overdue** / **Archive**) and held inside its Time Scope. Past its Due, an unfinished Task is **Overdue**, even inside a window that is still open. Without a Due of its own, a Keep Overdue Task's Time Scope is its Due, as before. An Overdue Task can be planned past its Time Scope, so late work can be rescheduled. The amber Overdue border now shows in every view, with a distinct selection colour, and screen readers announce it.

- **Started: work you have begun and put down.** A Task can now be **Started** beside To Do, In Progress and Done. **Alt+Enter** sets a To Do or Done task Started and flips In Progress ↔ Started (pause and resume); **Enter** on a Started task resumes it. Its icon is In Progress's with an open centre. Plan and Start show Started tasks, Do and the Zen View do not; *Start shows Started tasks* and *Do shows Started tasks* in Settings → General change that.

- **Plan and depend without opening the editor.** With a Task selected on the Mindmap, in the List View or in the Steps View, **P** opens the Scope Picker at it to set or clear its Plan (a Mindmap multi-selection is planned in one go), and **D** opens a search to add a dependency on a Task, Goal or Expectation. Every rule the editor applies still holds, and one **Ctrl+Z** takes either back.

  Every scope picker now works from the keyboard: arrows move, **Space** picks (a second pick makes a range), **Enter** steps in, **[** / **]** change period, `\` goes up a level and **Ctrl+Enter** applies.

- **A Habit's passed iterations fold into one node.** A run of passed iterations draws as one node with its tally, for example "Journal: 14 passed · 9 done, 5 missed", while the open iteration stays on its own. **Ctrl+/** opens it into a tree of years, seasons, months and weeks (only the levels the run spans), each with its own tally and opened one level at a time; it stays open across restarts. How many passed iterations it takes is set by *Collapse habit history after* in Settings → General (default 3), and applies in the Mindmap and the Steps View.

  **Ctrl+Alt+/** opens a cell and everything under it, folded Habit runs included, and pressing it again shuts them all.

- **Steps View: one level at a time.** A new view (**Ctrl+S**) draws the node you stand on as a header card and its direct children as cards beneath it, washed in their aspect's colour. A card shows the fields you would open the editor for, its first Info notes, and how many children it holds ("3 of 12"). The arrows move between cards, **Enter** steps into one (moving the same location the breadcrumb and **Ctrl+O** use), **Shift+Esc** / **Ctrl+Esc** climb out, **E** edits and **Space** cycles a status. Cards are created and deleted with the Mindmap's keys, and the **+** beside the header lists the kinds the Step can hold. A wide Step turns to pages: **PageUp** / **PageDown** or **[** / **]**, and the arrows carry over a page edge; card size is set per tab. A folded run of Habit history is a card you can step into, level by level.

- **A scope for the Plan preset.** While Plan is the preset, the top bar offers a *Plan scope*: pick a scope and the Mindmap, List and Steps Views show only the Tasks whose Time Scope (their own or inherited) lies within it. Each tab keeps its own; *Clear* removes it. *Plan scope keeps Tasks that overlap it* in Settings → General widens the match to overlapping and unscoped Tasks.

- **Plan View: fill one scope at a time.** A new view (**Ctrl+P**) with two panes: on the left, the **candidates** — relevant work that is unplanned or planned to the scope one rung up — and on the right, **what the scope already holds**. Moving a card across sets its Plan; moving it back puts it one rung up, among the candidates. It always reads under the Plan preset, and shares the tab's subtree and filters.
  - Any scope kind can be filled. **[** / **]** step to the previous and next scope, `\` or the **↑** button goes up to the parent scope, the scope's name opens a calendar, and with nothing selected **S**, **M**, **W**, **D** and **P** switch to seasons, months, weeks, days or parts of the day.
  - The planned pane is split into the scope's subscopes (the weeks of a month, the days of a week), each with its number and, where unambiguous, its initial; press it, or drag onto it, to plan into it.
  - **Shift+↑/↓**, **Shift+click** and **Ctrl+click** select several cards to plan at once, as one undo step; refusals are counted in the toast.
  - Each pane has its own **⋮** menu: *Show only planned to parent scope* and *Group by path* for the candidates, *Split by subscope* and *Include premorning* for the planned pane.
  - A move that breaks a containment rule is refused with the rule named, and planning a backlogged task takes it out of the Backlog. Habit occurrences can be planned one by one.

- **Commitments: things you keep rather than do.** "Asleep by 23:00", "no social media today". A **Commitment** is a new kind of node that lives anywhere a Task can, holds Tasks and other Commitments, and must have a window, its own or inherited. Instead of a status it has a **Verdict**: **Unresolved**, **Kept** or **Broken**. Only you ever set it: not the window closing, and not finishing its child tasks.

  Create one with **Shift+C**; it opens its editor, which says so if there is no window in reach. **Enter** (or a click on its status control) cycles Unresolved → Kept → Broken → Unresolved, and **X** records Broken outright, on the Mindmap and in the List View. On the Mindmap a commitment draws as a shield: hollow while unjudged, solid once judged, split when broken and struck through when the time to judge it ran out. In the List View commitments draw either in a band above the rows or as ordinary rows in the tree, chosen in Settings.

  **All** shows every commitment; **Plan**, **Start** and **Do** show only the ones still unjudged. A **Verdict Window** (days, weeks, months or seasons, inherited down the subtree) says how long after its window closes you can still answer; when it runs out the commitment archives still Unresolved. Commitments have no Plan, delegate, dependencies or on-exit choice. A Flow's **Instance Type** can be **Commitment**, so a nightly rule can repeat as a Habit with a Verdict Window of its own; unanswered repetitions archive unresolved rather than as missed. You can filter by Verdict.

- **Asynchronous tasks.** A Task marked **Asynchronous** starts a wait rather than finishing something: send the email, order the part. Toggle it with **W** or in the Task editor; it shows an hourglass badge and does not pass down to subtasks. Its editor then offers an Expectation section (title, tags, Time Scope, Check every): once the task is done, that wait appears beneath it to check on and release, and **E** on the wait edits that one wait. **Shift+W** opens the editor straight at that section. The List View can filter by Asynchronous and gather these tasks at the top (see List View).

- **Several windows, and the system tray.**
  - **Closing hides to the tray.** Closing the window puts Arlesh in the system tray instead of quitting, so it reopens instantly and the MCP endpoint keeps answering. Click the tray icon to show or hide the windows; its menu has **Show**, each open window, and **Quit**. **Ctrl+Q** also quits. Turn this off with *Close to tray* in Settings → Windows & tray.
  - **Tear-off windows.** Drag a tab out of the strip, or use the tab menu's **Move tab to new window**, to give it a window of its own with its own tabs and filters; drop a tab on another window, or use **Move tab to "…"**, to move it back. This works on Wayland too. **Ctrl+N** opens a new window at the current subtree, and **Ctrl+Alt+N** moves the current tab into one.
  - While several windows are open their titles are numbered, `Arlesh [1]`, `Arlesh [2]`, and the tray menu lists them so you can hide or show one alone. A window keeps its number while open.
  - An edit in one window shows in the others at once, including changes made by an agent.
  - Windows come back when you reopen Arlesh, at their size and position and with their tabs; one whose monitor is gone reopens on screen.

- **Backlog: a deliberate "not now" for Tasks.** Turn on **Backlog** in a Task's editor, or press **B** on the selected Task in any view, and it leaves **Plan** and **Start** along with everything beneath it; **All** still shows it, with a tray badge. Goals and Projects keep using **Frozen** for the same idea. **Alt+B** selects a new **Backlog** preset showing only backlogged work, and a **Backlog** pill in the Filter menu (Include / Exclude) overrides the preset as the Archived pill does.

  Backlog is separate from the status, so a started Task keeps its status while set aside. A Task is never both backlogged and planned: backlogging a planned Task asks to clear the Plan first, and planning a backlogged Task, or setting it In Progress, takes it out of the Backlog with a toast saying so. Backlog does not stop a Task from lapsing as Missed when its window closes.

- **Undo and redo.** **Ctrl+Z** reverses the last thing you did to the board, and **Ctrl+Shift+Z** or **Ctrl+Y** redoes it, in every view. One gesture is one step: a multi-node paste, a cascading delete, a drag that clamped descendants, or saving an editor (a save refused partway is rolled back in full). A notice names each step ("Undid: paste 5 nodes"), and an empty stack says "Nothing to undo". Inside a text field Ctrl+Z is the field's own undo. Undo does not cover filters, presets or navigation, never reverses changes made by an agent or a script, and starts empty each session.

- **Tabs.** Several places on the board can be open at once, each tab remembering its whole view: the subtree you entered, the view, the branch direction, every filter, the selection, collapsed branches and the canvas position. **Ctrl+T** opens a tab where you are (with fresh filters), **Ctrl+W** closes one, **Ctrl+Tab** / **Ctrl+Shift+Tab** cycle and **Ctrl+1**–**Ctrl+9** jump by position; these keep working while a dialog is open. The strip above the top bar has a **+**, an **×** per tab, closes a tab on middle-click and reorders by dragging. A tab is named after where it is (**All** for the whole board); right-click → **Rename tab** gives it a name of its own, and emptying the box hands it back to the automatic name. Closing a window's last tab closes the window.

  The clipboard, the theme and the display settings are shared between tabs; **Vertical layout** is per tab. Tabs come back when you reopen Arlesh — order, names, location, view and filters, but not the selection, collapsed branches or zoom. Your existing view reopens as the first tab.

  **The board alone:** **F11**, or **F** with nothing selected, hides the tab strip and the top bar; press it again to bring them back. Arlesh always reopens with them shown.

### Changed
- **Start shows what you can begin now.** Under the Start preset, in every view and over MCP:
  - Overdue Tasks, Goals and waits stay instead of dropping out; Missed items still drop out.
  - Work whose Time Scope or Plan has not begun yet is hidden, along with sub-steps that have no window or Plan of their own that has begun.
  - A blocked task no longer hides a subtask it depends on.
  - Anything archived, including an in-progress Task, stays out of Start, Do and the Zen View unless the Archived pill is on Include.

- **Copy and paste carry more, and say what they could not.** Copying a node now brings every Flow, Commitment and wait in its subtree. A Flow can be copied on its own, with its items, cycles, dependencies and Recurrence; a copied Habit starts with no completions, keeps its Start anchor, and its Target Node follows the copy when the target was copied too. Flow items can be copied within their own template. Work a Flow already started is copied as ordinary nodes that still name their Flow. When something cannot be pasted, the toast gives a sentence per reason, naming what you pasted, where it can go, or the rows you added to a Habit occurrence that stayed behind; everything legal is still pasted.

- **No red X over the Time Scope clock.** An item whose window has passed no longer draws its clock badge crossed out: an Overdue item has the amber border, and a Missed or Completed one the archive box.

- **A Habit keeps a clock instead of a Consumption.** The Consumption, Overlapping / Blocking and Catch-up choices are replaced by a **Clock**: **Window** (a new occurrence every window, done or not) with a choice for a missed one — **Archive** (archived as Missed), **Owed** (stays open, flagged Overdue) or **Overdue** (archived, and the open one carries it, Overdue until done) — or **Interval** (see Added). Existing Habits map as closely as they can: Destructive becomes Window + Archive, Overlapping Window + Owed, and Blocking Window + Overdue, with a Blocking Habit's stale open occurrence archived as Missed. Habit occurrences can now be Overdue and take a Due of their own. The Habit settings in the Flow editor start with the clock, and each choice explains itself in its tooltip.

- **Views are switched from a dropdown, each with its own chord.** **Ctrl+M** Mindmap, **Ctrl+L** List, **Ctrl+P** Plan, **Ctrl+S** Steps and **Ctrl+J** Zen; **Alt+L** no longer switches views. The status presets stay on **Alt+A/P/S/D/B**. Shortcuts that act on the tab rather than the view — leaving a subtree, **Ctrl+O** search, the filter menu — now work in every view.

- **Tab always creates a Task.** On the Mindmap (and in the new Steps View), **Tab** makes a Task child whatever is selected, instead of a child whose kind depended on the parent. Where a Task cannot go, nothing is created and a toast says where it can; inside a Flow template it makes a Task item. Other kinds have their own **Shift**+letter chords (see Added).

- **NSFW is now Private, and the Work filter is Private Mode, turned around.** Marking a node **Private** hides it and its subtree as before, but now by default: private nodes stay hidden until you turn **Private Mode** on in the Filter menu. If you had the Work toggle on, nothing changes; if it was off, your marked nodes are now hidden until you switch Private Mode on. A private node wears a crossed-out-eye badge in every view. No flags are lost.

- **A breadcrumb in the top bar replaces the back buttons.** Inside a subtree the bar shows the whole path, `Arlesh › CODE › ARLESH › Features`, in every view; click any step to go there. A path too long for the bar folds its middle into **…**, a menu of the hidden steps, and unfolds as the window widens. **Shift+Esc** and **Ctrl+Esc** are unchanged.

- **Searches leave archived nodes out.** **Ctrl+O**, the node results of **Ctrl+F**, and the Under and Depends on boxes no longer offer archived nodes; *Include archived nodes in search* in Settings → General brings them back. Delegated Tasks are offered only while the Delegated pill is on Include.

- **A denser Filter menu, with your filters shown where you set them.** Each dimension is one labelled row, with the switches at the top; the Archived and Backlog pills are no longer behind "Advanced" and now work in the List View too. A value you add stays in its row wearing its mode: click to cycle, **Delete** to remove. Adding now defaults to **All** (Shift adds as Any, Alt as Not), and chips cycle All → Any → Not. Blocked is one pill, with Alt for "Not blocked".

  The List View's **Antecedent** filter is now **Under**, and Dependency is **Depends on**. Under's search covers every node, and on a path header **Ctrl+click** a segment to show only what is under it, or **Alt+click** to hide it.

- **Habit occurrences are ordinary Tasks, Goals and Commitments.** A repetition is no longer read-only: **E** opens its editor, and what you save changes that occurrence only. You can plan it, backlog it, flag it, tag it, give it dependencies and block reasons, and hang Tasks, Goals, Commitments, Expectations and Infos under it, which belong to that occurrence alone and archive with it when its window passes. Its window stays its iteration's. Marking an occurrence done while it still holds unfinished work asks first. Deleting an occurrence archives that repetition and what it holds; moving it out of its iteration, changing its kind or copying it is refused with a reason. Editing the Habit's schedule now also asks before discarding occurrences you have added work to.

- **The board loads faster, and opening it no longer writes to it.** The Mindmap loads in one request instead of fifteen or more, and scopes (Seasons down to Parts of Day) are worked out from their dates instead of being stored on first use, so loading any view, or an agent's snapshot, only reads. If a Habit's repetitions cannot be worked out, a banner names it instead of the Habit quietly showing none. A week spanning New Year is always labelled with the year it starts in.

- **List View rows say where they live.** A run of rows sharing a location is topped by a path header — `Growth › CODE › ARLESH › Features` — starting below the subtree you are in and skipping ancestors already shown as rows.
